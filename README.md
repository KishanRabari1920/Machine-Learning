## Environment & Dependency Management

Used Python Virtual Environment (`venv`) for dependency isolation and package management.

Example:

```bash id="n3kvlz"
python -m venv .venv
```

Activate virtual environment:

### Windows

```bash id="0pzkc8"
.venv\Scripts\activate
```

### Linux / Mac

```bash id="3mbyx0"
source .venv/bin/activate
```

Install dependencies:

```bash id="xy5s49"

```
